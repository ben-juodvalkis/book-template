# fonts/

Self-hosted fonts live here so renders are **reproducible** — identical on your
machine, a collaborator's, and CI, with no network fetch at build time.

- **`fonts.txt`** — the manifest you edit (family, weight, style, source).
- **`fonts.css`** — generated by `./book fonts`; `@font-face` rules pointing at
  the files here. Link it from `src/master-header.html`.
- **The font files** (`.woff2` / `.ttf` / `.otf`) and their **license files** —
  committed so everyone renders with the exact same faces.

Only self-host fonts you may redistribute. [Open Font License](https://openfontlicense.org)
fonts qualify; keep each font's `OFL.txt` next to it here.

See **[`docs/FONTS.md`](../docs/FONTS.md)** for the full workflow.
